# OriginPixel OS 17

Open-source development workspace for an experimental Android 17 / LineageOS 24 Pixel 10 Pro XL ROM, including SmartIsland prototype modules, design tokens, and automated unit tests.

**Not a bootable ROM.** Device-specific SystemUI integration, full builds, and hardware validation remain incomplete. Do not flash these files.

This public export deliberately excludes private VPS configuration, backups, local environment inventories, and operational dashboards. Source development is currently maintained separately; public updates are curated.
